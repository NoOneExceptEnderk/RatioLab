## பதிவிறக்கமும் நிறுவலும்

**கீழேயுள்ள நிறுவியைப் பதிவிறக்கவும். Python, GTK மற்றும் தேவையான நூலகங்கள் இதில் சேர்க்கப்பட்டுள்ளன.**
மூலக் குறியீட்டைப் பதிவிறக்கவோ மென்பொருள் உருவாக்கக் கருவிகளை நிறுவவோ தேவையில்லை.

தற்போதைய வெளியீடு: **0.1.0 Preview 2** — இது ஆரம்பநிலைப் பதிப்பு; உங்கள் கருத்துகள் வரவேற்கப்படுகின்றன.

Windows மற்றும் Linux பதிவிறக்கங்களில் Fusion ஒருங்கிணைப்பு உள்ளது; Linux பதிப்பு,
Wine வழியாக இயங்கும் Fusion உடன் இணைகிறது. Windows பதிப்பில் வரைகலைத் திருத்தங்களும் உள்ளன.
macOS பதிவிறக்கங்கள் அசல் Preview 2 உருவாக்கத்தையே கொண்டுள்ளன.

Linux க்கு glibc 2.39 அல்லது அதற்குப் பிந்தைய பதிப்பு தேவை. எல்லா இயக்க முறைமைகளிலும் இணக்கமான வரைகலை இயக்கி தேவை.
Windows நிறுவியில் மின்னொப்பம் இல்லை; macOS பதிப்பு Apple அங்கீகாரம் (notarization) இல்லாத ad-hoc மின்னொப்பத்தைப் பயன்படுத்துகிறது.
அடையாளம் தெரியாத வெளியீட்டாளர் பற்றிய எச்சரிக்கையை உங்கள் இயக்க முறைமை காட்டலாம் அல்லது தொடங்குவதைத் தடுக்கலாம்.

[நிறுவல் வழிகாட்டி, தேவைகள் மற்றும் அகற்றுதல் (ஆங்கிலத்தில்)](../installation.md) · [அனைத்து வெளியீட்டுக் கோப்புகளும் சரிபார்ப்புத் தொகைகளும்](https://github.com/NoOneExceptEnderk/RatioLab/releases/tag/v0.1.0-preview.2)

## நீங்கள் செய்யக்கூடியவை

- ஒன்பது வகையான பற்சக்கரங்கள்/வேகக் குறைப்பான்களை உருவாக்கலாம்: நேர்பல் (spur), சாய்பல் (helical), இரட்டைச் சாய்பல் (double helical), கோள் அமைப்பு (planetary), சைக்ளாய்டல் (cycloidal), அலை உருமாற்றம் (strain wave), புழு (worm), இணைத் தண்டு (parallel shaft) மற்றும் உள்பல் (internal gear).
- அளவுருக்களைத் திருத்தி, கூறுகளைத் தேர்ந்தெடுக்கவும் மாதிரிப் புள்ளிகளின் அடிப்படையில் அளவிடவும் வசதியுள்ள இயங்கும் 3D மாதிரியை ஆராயலாம்.
- திட்டங்களைச் சேமிக்கலாம், மாற்றங்களைச் செயல்தவிர்க்கலாம், வரையறுக்கப்பட்ட அளவுருச் சேர்க்கைகளைத் தேடலாம், தனித்தனி நிலைகளில் குறுக்கீட்டுச் சோதனைகளை நடத்தலாம்.
- STEP, STL, SVG/DXF, கூறுப் பட்டியல்கள், கணக்கீட்டு அறிக்கைகள் அல்லது முழுத் தொகுப்புகளை ஏற்றுமதி செய்யலாம்.
- மாதிரிகளை SolidCraft அல்லது [Autodesk Fusion (ஆங்கில வழிகாட்டி)](../fusion360.md) க்கு அனுப்பலாம்; சேர்க்கப்பட்டுள்ள துணைநிரல் வழியாக, RatioLab அளவுரு மெட்டாடேட்டாவுடன் கூடிய STEP திட மாதிரிகளை Fusion பெறுகிறது.
- ஓர் ஏஜென்டுடன் இணைந்து பணியாற்ற, சேர்க்கப்பட்டுள்ள இணைய இணைப்பு தேவையற்ற [MCP துணைக் கருவியை (ஆங்கில வழிகாட்டி)](../mcp.md) பயன்படுத்தலாம். CAD ஒருங்கிணைப்புகள் விருப்பத்திற்குரியவை; CAD பயன்பாடு இல்லாமலேயே தனியாக ஏற்றுமதி செய்யலாம்.

## வடிவமைப்பைத் தொடங்குதல்

1. RatioLab ஐத் திறந்து ஒரு பற்சக்கர அல்லது வேகக் குறைப்பான் வகையைத் தேர்ந்தெடுக்கவும்.
2. பரிமாணங்களையும் ஒன்றிணைப்பு விருப்பங்களையும் அமைக்கவும்; முன்னோட்டத்தையும் தெரிவிக்கப்படும் முடிவுகளையும் ஆராயவும்.
3. உங்கள் திட்டத்தைச் சேமித்து, CAD அல்லது அச்சிடலுக்கான கோப்புகளைப் பெற **Export…** ஐத் தேர்ந்தெடுக்கவும்.

மேலும் விவரங்களுக்கு [பயனர் வழிகாட்டியையும் (ஆங்கிலத்தில்)](../user-guide.md) [எடுத்துக்காட்டுத் திட்டங்களையும்](../../examples/) பார்க்கவும்.
பயன்பாட்டின் இடைமுகம் ஆங்கிலத்தில் உள்ளது.

## தற்போதைய வரம்புகள்

இந்த முன்னோட்டப் பதிப்பு வடிவியல் மற்றும் இயக்கவியல் ஆய்வுக்கான மாதிரிகளை வழங்குகிறது. இது வலிமை,
சேவைக் காலம் அல்லது உற்பத்திக்கான தயார்நிலையைச் சான்றளிக்காது. குறுக்கீட்டுச் சோதனைகளும்
அளவீடுகளும் மேற்பரப்புகளிலிருந்து எடுக்கப்பட்ட மாதிரிப் புள்ளிகளைப் பயன்படுத்துகின்றன; புழு மற்றும் அலை உருமாற்ற
அமைப்புகள் ஆய்வு மாதிரிகளாகவே உள்ளன. ஏற்றுமதி செய்யப்பட்ட வடிவமைப்புகளைப் பயன்படுத்துவதற்கு முன்,
[துல்லியமும் வரம்புகளும் (ஆங்கிலத்தில்)](../user-guide.md#accuracy-and-limitations) என்ற பகுதியைப் படிக்கவும்.
