# Nominal calculations and technical references

Revision of 30 October 2026. The formulas were implemented in the project without copying code or tables from the references. `engineering.py`, `gear_measurement.py` and `backlash_solver.py` contain the calculations; `geometry.py`, `assemblies.py` and `geartrains.py` produce the geometry.

<a id="convenzioni"></a>

## Conventions

Dimensions in mm, forces in N, torque in N·m, speed in rpm and power in W. The signed ratio is **i = n input / n output**: a negative value means opposite directions. Output torque is reported as a magnitude, not as a reaction vector.

Efficiency is an assumption supplied by the user, not a result of the model. Fatigue sizing, Hertzian pressure, ISO 6336/AGMA checks, bearing life and elastic simulation are not implemented. A configured torque therefore does not represent an allowable torque. Harmonic and worm-wheel pairs remain geometric studies.

<a id="dentature-cilindriche-geometria-normale-e-trasversale"></a>

## Cylindrical teeth: normal and transverse geometry

For helical and double-helical gears, the entered module and pressure angle are **normal**:

```
mt = mn / cos β
αt = atan(tan αn / cos β)
d = z mt
db = d cos αt
da = d + 2 mn (ha* + x)
df = d − 2 mn (hf* − x)
sn = mn (π/2 + 2 x tan αn)
```

For spur teeth, β = 0. Addendum and dedendum use mn, including in helical gears: the previous revision incorrectly used mt for the heights. For an unshifted internal ring gear, the internal tip diameter is d − 2mn and the root diameter is d + 2,5mn.

Industrial source: [HPC Europe, Precision gears — Technical information, page 132](https://hpceurope.com/docFichesTechniques/PrecisionGears.pdf). Profile shift x and coefficients ha*/hf* are available for individual gears. In the new external pairs, x1 = x and x2 = −x: the zero sum preserves the theoretical centre distance while changing thicknesses and heights. For planetary gears, internal ring gears and studies, an independent profile shift that would make the pairs incompatible is not exposed.

The configured tangential backlash is the pair's total nominal backlash, divided between the two gears. The external root is now the envelope of the rounded tip of a normal rack: the transverse tip section is elliptical in helical gears. Profile shift x actually translates the rack; undercut trims the fillet at its intersection with the usable involute branch. The normal tip radius is min(0,3mn, limit preserving a half-land of 0,025mn). This is not a selected commercial tool. The internal ring gear instead uses a circular fillet tangent to the involute and root, explicitly not generated by a pinion-cutter. Methods, parameters and limits are in the per-part metadata; exported metadata reports the profile method, domain and limits.

### Nominal and generated tooth thickness

The reference normal thickness `normal_thickness` retains the nominal value
`sn` above for compatibility. The calculation report and `tooth_thickness`
metadata distinguish it from the analytical thickness of the constructed
profile with the configured allowance. With total **transverse** pair backlash
`j`, each gear loses `j/2` of transverse reference arc thickness, or
`j cos β/2` of normal reference arc thickness. These are reference-circle
dimensions, not the working backlash at an increased centre distance.
`gear_dimensions` additionally exposes explicit `nominal_reference_*_thickness_mm`
and `reference_*_thickness_with_allowance_mm` normal/transverse fields. These
remain theoretical reference arcs until actual profile metadata confirms the
useful involute interval; requesting dimensions alone does not construct or
validate a tooth profile.

For a positive physical radius `ry` on the useful involute, define
`αyt = acos(rb/ry)`, `inv α = tan α − α` (angles in radians), and `σ = +1`
for an external tooth or `−1` for an internal tooth. RatioLab uses positive
tooth counts/radii and this explicit sign; ISO's `z/|z|` has the same role.

```
ψ nominal = (π/2 + 2x tan αn)/z
ψ generated = ψ nominal − j/(4rp)
ψy = ψ + σ [inv αt − inv αyt]
sy transverse arc = 2ry ψy
sy transverse chord = 2ry sin ψy
tan βy = (ry/rp) tan β
sy normal arc = sy transverse arc cos βy
```

Evaluate each nominal/generated angle at the reference radius and actual tip
radius. Internal rings use `x=0` and `ra=rp−ha*mn`; their useful involute runs
from the tip to the tangent root blend. External involutes run from the
trimmed rack intersection to the tip. A reference circle outside that useful
interval has no reported generated thickness; its nominal reference value
remains identifiable. The generated tip transverse chord and its ratio to
`mn` quantify a thin tip geometrically. No minimum safe tip thickness or
structural capacity is inferred. Pointed/overlapping profiles remain rejected
by the existing generator.

For `z=24`, `mn=2 mm`, `αn=20°`, `β=x=0` and `j=0.15 mm`, the nominal
reference arc is `3.141592653589793 mm` and the generated reference arc is
`3.066592653589793 mm`. The generated tip chord is `1.349699272061169 mm`.
For helical/double-helical teeth the same transverse construction is used;
the reported normal arcs include the helix angle at each respective radius,
while chords are explicitly transverse. Widths precede the profile's chord
sampling and are not sampled-surface tolerances. Thickness results in the
application cover cylindrical individual gears, parallel/internal pairs and
planetary members. They do not describe deformed strain-wave teeth, worm
envelopes, cycloidal profiles or bevel teeth.

Reference: ISO 21771:2007, 4.7.1–4.7.2, equations (38)–(41), and 4.7.5,
equations (48)–(49). These equations and the physical sign translation are
used as dimensional references; this is not a claim of complete ISO conformity.

### Wildhaber span over teeth

`gear_measurement.wildhaber_span` reports the theoretical base tangent length
over an integer number of teeth `k` for **external spur involutes**. Results
show a recommended span; the calculation report and JSON export list every
usable `k` so the user can choose a different span without changing the model.
The recommendation places the symmetric contacts nearest the reference
circle; it is a geometric convenience, not a gauge or tolerance specification.

With actual reference half angle `ψ` including the allowance above, define:

```
pb = 2πrb/z = m cos αt π
sb = 2rb (ψ + inv αt)
Wk = (k − 1) pb + sb
contact roll = Wk/(2rb)
contact R = sqrt(rb² + (Wk/2)²)
```

All lengths are mm; involute angles use radians. Each positive integer `k`
is tested against the actual generated involute interval after rack root
trimming, up to the tip. Negative/zero roll and reversed or overlapping
flank contacts are rejected. Both symmetric jaw contacts must lie within
that interval. Root/tip contact margins are reported; a supported profile
can have **no usable integer span**. The algorithm tests actual geometry
instead of accepting a rounded recommended tooth count unchecked. It does
not test physical gauge access, jaw dimensions, chamfers, tolerances, or
off-centre rocking of the instrument.

The allowance changes each span by `−(j/2) cos αt`. As an independent
benchmark, `m=3 mm`, `z=24`, `αt=20°`, `x=0.4`, `j=0`, `k=4` gives
`W4=32.82662724866363 mm`, agreeing with the rounded `32.8266 mm` in
KHK Technical Data section 5.2, Table 5.10. Tests additionally reconstruct
opposing involutes and check that the parallel jaws are tangent at their
reported contact radii.

The supported application scope includes external spur members of individual,
parallel, internal-pair and planetary models. Internal teeth and helical or
double-helical flat-jaw spans explicitly report unsupported: no spur formula
is substituted for the helical usable-facewidth checks. Harmonic, worm,
cycloidal and bevel profiles have no span result. `measurement_geometry`
in profile metadata records the undeformed analytic involute inputs and does
not establish that a special/deformed family supports this measurement.

References: ISO 21771:2007 A.2.1, equations (A.4)–(A.6) for span limits and
length, and (A.9) for the symmetric contact circle. Helical facewidth conditions
(A.7)–(A.8) are outside the implemented scope. See also the manufacturer's
[KHK tooth-thickness article, Part II](https://khkgears.us/gear-news/determining-tooth-thickness-of-various-gear-types-part-ii/).

### Theoretical measurements over balls and rollers

**Tools → Gear metrology…** queries an explicitly selected generated cylindrical
member with a user-selected diameter and either balls or axial rollers. The
query leaves project parameters and history unchanged. Its separate TXT/JSON
export records the source position, component, document revision, normalized
parameters, actual involute inputs, gauge type/diameter and validity outcome.
Parameter edits, including incomplete numeric text, invalidate the displayed
query. The standard calculation report and existing analysis exports include
a default theoretical ball measurement for each supported cylindrical member.
The default diameter targets a useful contact nearest the reference circle,
then the useful interval midpoint; it is not a stock gauge recommendation.

`gear_measurement.over_gauges` supports **external and internal spur involutes**,
with even or odd positive physical tooth count `z`. Let `D` be gauge diameter,
`db=2rb` base diameter, `ψ` the actual reference tooth half angle, and
`inv(a)=tan(a)-a`. All lengths are mm and angles in these equations are radians:

```
external: ηb = π/z − ψ − inv(αt); inv(αK) = D/db − ηb
internal: ηb = π/z − ψ + inv(αt); inv(αK) = ηb − D/db
external: rollM = tan(αK) − D/db
internal: rollM = tan(αK) + D/db
dK = db/cos(αK); contact R = rb sqrt(1 + rollM²)
even teeth: centre separation = dK
odd teeth: centre separation = dK cos(π/(2z))
external: M = centre separation + D  (over gauges)
internal: M = centre separation − D  (between gauges)
```

The inverse involute is solved on `0 ≤ αK < π/2`. Negative inverse targets
have no usable symmetric seat in this domain. In particular a formal negative
internal branch would require a gauge radius larger than the local concave
involute curvature radius `rb rollM`, causing local penetration. Equality at
zero centre pressure is rejected as an unstable osculating contact. Positive
contact roll is required before computing its radius; squaring cannot restore
a reverse involute branch. Both contacts must lie on the actual useful
involute interval after root trimming/blending, within their tooth-space
flanks. Explicit outcomes distinguish absent solution, reverse branch,
root/blend contact, beyond-tip contact, root-envelope intersection, unproven
jaw clearance and overlapping gauges. An unavailable query has no valid `M`.

The root-circle envelope and full tip-circle jaw-clearance checks are
conservative: they may exclude usable gauges whose exact local access differs
from a complete circle. The odd-tooth clearance test uses the actual measuring
axis. These checks do not establish axial assembly/access around hubs or
supports, finite roller length, instrument geometry, tolerances or elastic
contact. The result is for the isolated undeformed member. Internal root
geometry remains the application's circular blend, not a shaping-cutter
prediction.

On spur teeth a ball has point contacts and an axial cylindrical roller has
line contacts, with the same ideal transverse dimension. Helical and
double-helical balls/rollers explicitly report unsupported: their distinct
three-dimensional contact and placement equations are not replaced by these
spur formulas. Harmonic, worm, cycloidal and bevel families are excluded.

References: ISO 21771:2007 A.5 equations (A.42)–(A.46), A.6, and A.7 equations
(A.47)–(A.48), translating signed ISO tooth counts to positive physical radii
and the explicit internal/external signs above. Independent benchmarks from
KHK Technical Data section 5.3, Tables 5.14 and 5.18, at `m=1 mm`, `α=20°`,
`x=j=0`, `D=1.7 mm`, are external `z=20`, `M=22.29409294937739 mm`
(published `22.2941`) and internal `z=40`, `M=37.595115183247216 mm`
(published `37.5951`). Tests independently reconstruct the flank curve and
verify circle tangency, local nonpenetration and centre-to-centre dimensions
for even/odd counts and actual backlash allowances. See the manufacturer's
[KHK tooth-thickness article, Part III](https://khkgears.us/gear-news/determining-tooth-thickness-of-various-gear-types-part-iii/).
These are theoretical geometric dimensions, without a full ISO conformity or
strength claim.

## Contact and centre distance

For balanced external pairs, the working centre distance can be increased:

```
a0 = (d1 + d2)/2
αw = acos(a0 cos αt / a)
g1 = sqrt(ra1² − rb1²)
g2 = sqrt(ra2² − rb2²)
εα = (g1 + g2 − a sin αw) / (π mt cos αt)
εβ = b active |sin β| / (π mn)
ε total = εα + εβ
Δj = 2a [inv(αw) − inv(αt)], where inv(α) = tan α − α
j working = j nominal × a/a0 + Δj
```

For an internal pair, a0 = (d2 − d1)/2 and the numerator of εα becomes g1 − g2 + a sin αw; ra2 is the internal tip radius. The historical contact_transverse/contact_total values retain the nominal tip/base calculation. profile_contact_transverse/profile_contact_total instead intersect the two actual involute intervals after trimming/blend; the report exposes both and warns if the second total is less than one. The corrected calculation excludes contact on fillets and does not check 3D collisions or chamfers. These are not loaded-contact analyses. Source: [Drivetrain Hub, Geometry / Helical Gears, Gear Mesh and Contact Ratio sections](https://drivetrainhub.com/notebooks/gears/geometry/Chapter%203%20-%20Helical%20Gears.html).

The generator rejects total contact ratio < 1 and involute interference in the new pairs. For double-helical gears, b active is **(width − gap)/2**, even when the gap is zero: the two halves are not treated as one continuous helix. Δj is additional to the backlash already configured.

### Inverse centre distance for working backlash

**Tools → Solve working backlash…** inverts the exact forward relation above
for the existing **parallel external pair** family, with spur, helical or double
helical teeth. The requested quantity is transverse circumferential (tangential)
**working** backlash in mm. It is neither the normal tooth allowance nor radial
backlash. ISO 21771:2007, 5.5.1–5.5.3, equations (100)–(104), distinguishes
these quantities; this feature makes no full-standard conformity claim.
The normal module and pressure angle are converted to the transverse plane using
the same `mt` and `αt` as the generated pair; the sign of β changes hand, not
this scalar centre-distance relation. Balanced shifts remain `x1=−x2`.

For `j0≥0`, `0<αt<π/2` and `a≥a0`, the derivative is

```
dj/da = j0/a0 + 2 [inv(αw) − inv(αt)] + 2 tan(αw) > 0
```

There is at most one solution in the exposed `center_extra` domain, currently
`0–5 mm`. Bounded bisection solves it without replacing the involute relation
with a small-angle approximation. Targets below the reference-distance backlash
or above the parameter limit are explicitly unreachable (only numerical rounding
at a bound is clamped). The valid current pair supplies `a0`: the solver does not
require a usable reference-distance pair, because increasing centre distance can
resolve below-base-circle interference. Length scaling scales `a0`, `j0`, the
target and the solved increase together.

Every candidate is regenerated with all other normalized parameters fixed.
The engine's forward backlash and an independent scalar evaluation must both
reproduce the target within `1e−10 × max(1 mm, target)`. Generation checks nominal
contact, involute interference and parameter/hardware limits. The proposal also
requires **usable** total involute contact ratio ≥1 after root trimming/blending;
the ordinary generator's nominal ratio alone is insufficient. For double helices
the existing overlap ratio uses one active half `(width−gap)/2`, including a
zero-gap join. A mathematically reachable root can therefore be geometrically
rejected; it is never silently replaced with another backlash value.

The worker then runs the shared discrete 3D interference checker. The UI exposes
angular step, pose and time budgets; the report includes settings, coverage,
resource limits and every finding. Default preview settings are ≤30° steps,
721 poses, 60 s, 0.01 mm boundary tolerance, 128 parts and 300,000 triangles.
Apply requires complete sampled coverage, no intersection/containment and no
unresolved boundary outside a labelled same-kinematic-member interface. Those
same-member contacts (for example a shaft touching its gear bore) remain listed
as unresolved; their expected label never suppresses an intersection. Complete
sampled coverage is not a continuous-clearance, loaded-contact or strength proof.
Users can request finer steps and more time; incomplete checks cannot be applied.

The standalone static 3D preview does not modify the project canvas, inspection
pose or motion. **Apply centre distance** regenerates and verifies the candidate
again, then records one intentional Undo step while retaining document identity,
path, saved baseline and other-family drafts. Edits, incomplete raw text,
Undo/Redo, document replacement, cancellation and window closure invalidate the
proposal and late worker callbacks. The independent query export saves TXT/JSON
with source parameters/revision, target, proposed values, actual forward result,
usable contact ratio, complete discrete report and proposed/applied context.
It uses the same staged directory transaction as other exports. Ordinary model
calculation and CAD/BOM analysis exports continue to include the resulting
forward mesh quantities after Apply.

Independent numeric benchmark: `z1=20`, `z2=60`, `mn=2 mm`, `β=0`, `α=20°`,
`x1=x2=0`, `j0=0.15 mm` gives `a0=80 mm`. Targets `0.223414903130557`,
`0.372826053062876` and `0.922262444591769 mm` yield increases `0.1`, `0.3`
and `1 mm` respectively. Tests verify full generation and both helix hands,
double-helix half widths, unreachable roots, nominal-versus-usable contact,
normalization, stale results and history. The transverse geometry reference is
[Drivetrain Hub, Geometry / Helical Gears, Gear Mesh and Contact Ratio sections](https://drivetrainhub.com/notebooks/gears/geometry/Chapter%203%20-%20Helical%20Gears.html).
Internal and planetary centre adjustment is outside the implemented domain.

## Undercut and internal interference

The indicative standard-rack condition is x minimum = ha* − zv sin²αn / 2, with zv = z for spur teeth and zv ≈ z/cos³β for helical gears. The virtual-tooth check remains a design approximation. The geometric warning now uses the actual rounded-rack threshold x_min=(hf*mn−ρ(1−sinαn)−rp sin²αt)/mn, distinct from the indicative virtual-tooth limit; the profile records whether the branch was trimmed. Source for the standard limit and the role of profile shift: [KHK, Technical Data, sections 3.5–3.6](https://d2t1xqejof9utc.cloudfront.net/files/227482/gear_guide1.pdf?1634738312=).

The new internal pairs require a tooth-count difference > 9, in addition to the base-circle check. This is a conservative generator filter; the KHK note on the limit of 9 concerns standard teeth at 20° and is not a guarantee for other angles. Cutting interference and tool profile remain to be checked. Source: [KHK, Internal ring gears — design and considerations](https://khkgears.us/media/beqhhrye/gear-solutions_khk_internal-ring-gears-design-and-considerations.pdf).

The old 18/18/54 spur planetary preset can enter the area below the base circle in the planet-ring pair. It is retained for compatibility, with an explicit warning and theoretical contact ratio in the report. It is not declared interference-free. A 24/24/72 combination avoids this specific warning and retains the 4:1 ratio; this does not make it a strength-rated design.

## Kinematics and forces

```
External pair: i = −z2/z1
Fixed-axis internal pair: i = +z2/z1
Compound with two external stages: i = (z2/z1)(z4/z3)
Fixed-ring planetary: i = 1 + zr/zs
P input = T input × n input × 2π/60
n output = n input / i
|T output| = T input × |i| × η overall
Ft = 2000 |T| / d working
Fr = Ft tan αw
Fa = Ft tan β
```

In the compound train, η stage = √η overall is an explicit assumption for estimating intermediate torque. The coaxial variant requires equal centre distances; input and output shafts are axially separated. The two intermediate gears must be rigidly connected, but the mechanical connection has not yet been designed. Teaching sources: [JNTUA/JNTUK, Gear Trains, lectures by Prof. N. Mohan Rao](https://www.jntua.ac.in/gate-online-classes/registration/downloads/material/a159033042164.pdf), [University of Arkansas, Introduction to Mechanical Design and Manufacturing — Gearing Systems](https://uark.pressbooks.pub/mechanicaldesign/chapter/gearing-systems/). The latter sometimes uses the reciprocal ratio convention; here, i = n input/n output is always explicit.

The forces are nominal references on the driving gear, not complete support reactions. Fr and Ft are magnitudes; the sign of Fa follows the pinion's reference hand and does not by itself determine the direction of the reaction in the assembly. For double-helical gears, Fa is the conservative full-torque reference for a single helix; overall cancellation requires symmetric loads. Independent cross-check example: T = 100 N·m, d = 40 mm, αw = 21,515° → Ft = 5000 N, Fr ≈ 1971,1 N. Source: [Drivetrain Hub, Strength / Force Analysis](https://drivetrainhub.com/notebooks/gears/strength/Chapter%201%20-%20Force%20Analysis.html).

For planetary gears, the coaxiality, equal-spacing and inter-planet distance conditions are retained. The sun-planet and planet-ring contact ratios of each stage are reported; load sharing is not invented by simply dividing torque by the number of planets. Reference: [Drivetrain Hub, Geometry / Planetary Gears](https://drivetrainhub.com/notebooks/gears/geometry/Chapter%204%20-%20Planetary%20Gears.html).

## Cycloidal

The profile remains the inward normal offset of the roller-centre trajectory. **Profile clearance**, **output-hole clearance**, **assembly axial clearance** and **distance between the two discs** are distinguished. The output-hole radius is r pin + eccentricity + output clearance. If an old configuration does not specify the new values, the old profile clearance and old axial clearance are used, respectively.

Adaptive sampling compares the midpoint and quarter points of each interval with the chord. This is a numerical threshold, not a manufacturing tolerance or a proven global bound. The curvature check uses at least 4096 samples and a 2% margin against offset cusps; it is not an analytical proof of cusp absence for every parameter. The ratio is −(N rollers − 1).

The separation of clearances is motivated by [Chen et al., ASME Journal of Mechanical Design, 2017, Analysis of a Cycloid Speed Reducer Considering Tooth Profile Modification and Clearance-Fit Output Mechanism](https://doi.org/10.1115/1.4035541). Normal profile modifications are discussed in [A New Tooth Profile Modification Method of Cycloidal Gears in Precision Reducers for Robots, Applied Sciences 2020](https://www.mdpi.com/2076-3417/10/4/1266). Their optimisation and elastic load-sharing model are not implemented: clearance alone does not allow stress or accuracy under load to be estimated.

## Worm and strain wave

For the worm pair, **m is the axial worm module**: lead L = π m starts,
γ = atan(m starts / worm diameter), mn = m cos γ and
αn = atan(tan αaxial cos γ). The wheel uses the conjugate screw/hob envelope,
with an extended generating tip for root clearance and explicit generating
thickness for backlash. ZA and ZI, both hands and independent wheel bores are
supported within the checked geometric domain. Signed ratio follows world
+X worm / +Z wheel, with the wheel centre on negative Y:
i = hand × wheel teeth / starts. Geometry alone does not establish efficiency
or self locking. See [worm equations and primary references](worm.md).

For a two-lobe strain wave, zc = zf + 2 and
2 ωwave + zf ωflex − zc ωring = 0. Fixed ring gives i = −zf/2;
fixed flex gives i = +(zf+2)/2. The rigid ring is generated from the complete
matching tooth sweep under the prescribed pitch-arc/normal ellipse map. The
reference tooth-thickness allowance and numerical cell-enclosure relief are
separate reported quantities. The same immutable material map drives preview
and discrete interference poses. This is not an elastic, fatigue or loaded
contact solution. See [strain-wave equations and references](strain-wave.md).

## Kinematic arrangements

The ratio is input/output. Planetary, cycloidal and strain wave solve all six member permutations with zero speed for the fixed member. The two-stage planetary propagates speed and sign between the two stages. Parallel-axis, internal-ring and worm pairs allow input and output to be reversed; for the worm, this does not guarantee backdrivability. See [IO-MODELS.md](io-models.md).


## Static worm backdrivability

The driving member is selected by `io_scheme`: `reverse` means wheel input,
whereas motor-speed sign changes rotation direction only and is not a
backdrivability criterion. Existing per-family numeric speed ranges still apply:
worm operating data currently accepts 0 to 100000 rpm. Both ZA and ZI
use their reference-cylinder lead and normal pressure angles for this limited
static tooth-contact screen. Lengths `mx` (axial module) and `d` (worm pitch
diameter) are in mm; starts `s` is dimensionless; pressure `alpha_x` is the axial
pressure angle in degrees in the interface. Angles in the equations are radians.
The optional `worm_static_friction` is the explicit nonnegative, finite static
tooth-contact friction coefficient `mu`; there is no default or material table.

```
gamma = atan(mx*s/d)
alpha_n = atan(tan(alpha_x)*cos(gamma))
Ft1/Fn = cos(alpha_n)*sin(gamma) - mu*cos(gamma)
mu_critical = cos(alpha_n)*tan(gamma)
```

KHK, **Calculation of Gear Dimensions**, §4.6(4), Eq. (4.27), resolves the force
on a passive, unassisted worm shaft when the wheel drives: `Fn` is the tooth
normal force [N] and `Ft1` the worm circumferential driving force [N]; their ratio
is dimensionless. The criterion concerns reference-cylinder tooth contact at
static startup. Positive driving force requires
`mu < mu_critical`; equality gives no positive startup margin and is refused
along with larger coefficients. This is a static Coulomb tooth-contact model.
The hand and speed sign do not change this magnitude criterion. [KHK primary
technical reference](https://khkgears.net/new/gear_knowledge/gear_technical_reference/calculation_gear_dimensions.html).

The shared backend/UI evaluator blocks only a wheel-driven request established
as `not_backdrivable` in this model. Worm-input configurations remain valid.
A smaller explicit coefficient produces `potentially_backdrivable`, not a startup
or sustained-motion guarantee. An omitted coefficient produces `indeterminate`;
legacy reverse projects continue to load with an explicit ideal-kinematics
warning. Invalid physical fields are rejected rather than discarded. Projects
save the coefficient; calculation metadata records the state, assumptions,
reference, angles and threshold. There is no override of a supplied forbidden
coefficient: removing it explicitly withdraws the physical evaluation.

Bearings, seals, preload, elastic deformation, vibration, changed lubrication,
temperature and operating loads are outside the model. No safety-brake,
load-holding, strength or certification claim follows from either state.
The manufacturer's explanation also distinguishes static self-locking from the
loss of holding under shocks or vibration and identifies lubrication, surface
condition and temperature as relevant to friction; no heuristic angle or guessed
material coefficient is adopted here. [BJ-Gear technical explanation](https://www.bj-gear.com/about-bj-gear/information-centre/technical-knowledge-base/how-to-interpret-the-self-locking-mechanism-of-worm-gearboxes).

For strain-wave drives, output-member input remains `indeterminate` without
hardware-specific breakaway torque and conditions. Harmonic Drive's **CSD Gear
Units**, Engineering Data, printed p. 22 (PDF p. 36), defines backdriving torque
as the output torque needed to start a no-load input shaft at +20 °C; printed
p. 215, Table 215-2 supplies product-specific values with application-dependent
qualifications. Such catalog measurements cannot certify RatioLab's generated
hardware and do not justify a family-wide irreversibility rule. [Harmonic Drive
primary catalog](https://www.harmonicdrive.net/_hd/content/documents1/CSD_GearUnits.pdf).
